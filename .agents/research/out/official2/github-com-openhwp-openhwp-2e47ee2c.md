# OpenHWP
[](https://github.com/openhwp/openhwp#openhwp)
HWP(한글 워드프로세서) 문서를 읽고 쓰기 위한 Rust 라이브러리입니다.
> 본 제품은 한글과컴퓨터의 한/글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.
## 크레이트
[](https://github.com/openhwp/openhwp#%ED%81%AC%EB%A0%88%EC%9D%B4%ED%8A%B8)  
| 크레이트  | 설명  | 용도  |  
| --- | --- | --- |  
| [`hwp`](https://github.com/openhwp/openhwp/blob/main/crates/hwp)  | HWP 5.0 바이너리 파서  |  `.hwp` 파일 읽기  |  
| [`hwpx`](https://github.com/openhwp/openhwp/blob/main/crates/hwpx)  | HWPX XML 파서  |  `.hwpx` 파일 읽기/쓰기  |  
| [`ir`](https://github.com/openhwp/openhwp/blob/main/crates/ir)  | 중간 표현  | HWP ↔ HWPX 변환  |  
| [`document`](https://github.com/openhwp/openhwp/blob/main/crates/document)  | 에디터용 문서 모델  | 문서 편집기 개발  |  
| [`primitive`](https://github.com/openhwp/openhwp/blob/main/crates/primitive)  | 공유 기본 타입  | 단위, 색상, ID 등  |  
## 설치
[](https://github.com/openhwp/openhwp#%EC%84%A4%EC%B9%98)

```
[dependencies]
hwp = { git = "https://github.com/openhwp/openhwp" }   # HWP 파일 읽기
hwpx = { git = "https://github.com/openhwp/openhwp" }  # HWPX 파일 읽기/쓰기
```

## 사용 예시
[](https://github.com/openhwp/openhwp#%EC%82%AC%EC%9A%A9-%EC%98%88%EC%8B%9C)
### HWP 파일 읽기
[](https://github.com/openhwp/openhwp#hwp-%ED%8C%8C%EC%9D%BC-%EC%9D%BD%EA%B8%B0)

```
use hwp::HwpDocument;

let bytes = std::fs::read("document.hwp")?;
let doc = HwpDocument::from_bytes(&bytes)?;

println!("{}", doc.extract_text());
```

### 암호화된 HWP 파일
[](https://github.com/openhwp/openhwp#%EC%95%94%ED%98%B8%ED%99%94%EB%90%9C-hwp-%ED%8C%8C%EC%9D%BC)

```
let doc = HwpDocument::from_bytes_with_password(&bytes, "비밀번호")?;
```

### HWPX 파일 읽기
[](https://github.com/openhwp/openhwp#hwpx-%ED%8C%8C%EC%9D%BC-%EC%9D%BD%EA%B8%B0)

```
use hwpx::header::Head;

let xml = std::fs::read_to_string("Contents/header.xml")?;
let head: Head = hwpx::from_str(&xml)?;
```

### HWP → HWPX 변환
[](https://github.com/openhwp/openhwp#hwp--hwpx-%EB%B3%80%ED%99%98)

```
use hwp::HwpDocument;
use ir::Document as IrDocument;

let hwp = HwpDocument::from_bytes(&bytes)?;
let ir: IrDocument = hwp.into();
// ir을 hwpx로 변환...
```
