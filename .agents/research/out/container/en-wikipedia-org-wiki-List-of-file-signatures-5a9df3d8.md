A [file signature](https://en.wikipedia.org/wiki/File_format#Magic_number "File format") is data used to identify or verify the content of a file. Such signatures are also known as _[magic numbers](https://en.wikipedia.org/wiki/Magic_number_\(programming\)#In_files "Magic number \(programming\)")_ or _magic bytes_ and are usually inserted at the beginning of the file.
Many [file formats](https://en.wikipedia.org/wiki/File_format "File format") are not intended to be read as text. If such a file is accidentally viewed as a text file, its contents will be unintelligible. However, some file signatures can be recognizable when interpreted as text. In the table below, how the file signature appears when interpreted as text in the common [ISO/IEC 8859-1](https://en.wikipedia.org/wiki/ISO/IEC_8859-1 "ISO/IEC 8859-1") encoding is shown, with unprintable characters represented as the [control code](https://en.wikipedia.org/wiki/Control_code "Control code") abbreviation or symbol, or [codepage 1252](https://en.wikipedia.org/wiki/Windows-1252 "Windows-1252") character where available, or a box otherwise. In some cases the space character is shown as ␠.
