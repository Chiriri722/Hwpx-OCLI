# 한셀 SDK
한셀 SDK
함수, 수식 계산, 데이터 분석 등 스프레드시트의 기능을 고객사의 제품과 서비스에 탑재할 수 있는 SDK  
스프레드시트가 가진 420여 개의 모듈을 특정 플랫폼에 종속되지 않는 형태로 제공합니다.
## 주요 기능
수년간의 서비스 운영으로 안정성이 확보된 한컴 한셀 SDK를 다량의 데이터를 다루는 모든 곳에 탑재할 수 있습니다.
![셀 편집 기능과 안정성 강조를 보여주는 스프레드시트 편집 화면 이미지](https://www.hancom.com/images/product/sdk-hcell-features-img.png)
### 기능 다양성
피벗테이블, 필터 등 많은 스프레드시트 기능 지원
### 경량화
경량화된 모듈로 부담없이 타 솔루션과 통합
### 호환성
MS 엑셀 포맷과의 높은 호환성
### 안정성
한국의 오피스 제품 한셀의 계산엔진 모듈 사용해 안정적  
한국 외 대만, 북유럽 등에 도입된 레퍼런스 보유
### 많은 함수 지원
다양한 성격의 420여 개 함수군 보유,  
Addin 함수 추가하여 연동 가능
