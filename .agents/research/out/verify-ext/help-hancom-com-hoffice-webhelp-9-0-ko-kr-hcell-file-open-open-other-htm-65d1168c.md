# 다른 형식의 파일 불러오기
 |  
| --- | --- |  
|   |  파일-불러오기  |  
한/셀은 한/셀 문서(*.cell), 넥셀 문서(*.nxl)뿐만 아니라 다른 파일 형식을 직접 읽어 편집할 수 있습니다.
엑셀 문서(*.xls, *.xlsx, *.xlsm), 하나시트 문서(*.wkt), 텍스트 문서(*.txt; *.prn; *.csv), 인터넷 문서(*.html; *.htm), dBASE 문서(*.dbf), ODF 스프레드시트 문서(*.ods), 서식 파일(*.hcdt, *.nxt) 등 다양한 형식의 파일을 불러올 수 있습니다.
##  ![](https://help.hancom.com/hoffice/webhelp/9.0/ko_kr/hcell/images/dot.gif) 따라 하기
### 파일 불러오기
  1. [[파일-불러오기](https://help.hancom.com/hoffice/webhelp/9.0/ko_kr/hcell/file/open/open.htm)]를 실행합니다.
  2. [불러오기] 대화 상자가 나타나면 [파일 형식] 목록 단추를 눌러 'ODF 스프레드시트 문서(*.ods)'를 선택합니다.
  3. [찾는 위치]에서 원하는 ODF 스프레드시트 문서가 있는 폴더를 선택하면 파일 목록 상자에 해당 폴더 안에 들어 있는 ODF 스프레드시트 문서(*.ods)만 표시됩니다.
  4. 파일 목록 상자에서 원하는 파일을 선택한 다음 [열기] 단추를 누릅니다.
  5. 선택한 파일이 문서 창에 열립니다.


##  ![](https://help.hancom.com/hoffice/webhelp/9.0/ko_kr/hcell/images/dot.gif) 참고
### 파일 형식 지정
[불러오기]를 실행하여 다른 파일 형식을 불러오려면 [파일 형식]에서 원하는 파일 형식을 선택합니다. 또는 [파일 이름]에 '*.txt'와 같이 파일 형식을 직접 입력할 수도 있습니다. '*.txt'라고 입력하면 txt라는 확장자를 가진 파일들의 목록을 보여 줍니다.
  * **모든 스프레드시트 문서(*.cell; *.hcbk; *.hcdt; *.hca; *.nxl; *.nxk; *.nxt; *.nav; *.xls; *.xlsx; *.xlsm; *.ods)**


한/셀에서 한/셀 문서를 포함한 다른 스프레드시트 프로그램 문서를 읽어 들입니다. 한/셀 문서 및 한/셀 서식 파일 외에 엑셀 통합 문서와 ODF 스프레드시트 문서를 읽어 들입니다.
  * **한/셀 통합 문서(*.cell; *.hcbk; *.hcdt; *.hca)**


한/셀에서 저장한 문서 외에 백업 파일(*.hcbk), 서식 파일(*.hcdt), 자동 저장 파일(*.hca) 형식의 문서를 읽어 들입니다.
  * **넥셀 2003-2007 통합 문서 (*.nxl; *.nxk; *.nxt; *.nav)**


이전 판인 넥셀 2003-2007 파일 형식의 문서를 읽어 들입니다.
  * **엑셀 통합 문서 (*.xls; *.xlsx; *.xlsm; *.xltx; *.xltm; *.xlt)**


마이크로소프트 엑셀 통합 문서를 읽어 들입니다.
  * **하나시트 문서(*.wkt)**


하나 스프레드 시트 문서를 읽어 들입니다.
  * **텍스트 문서(*.txt; *.csv; *.prn)**


텍스트 파일 형식이란 일반적인 문자, 숫자, 그리고 각종 기호로만 이루어진 가장 기본적인 형태의 정보를 담고 있는 문서 파일 형식으로, 이는 특수한 제어 문자나 그래픽 문자를 포함하지 않습니다. 텍스트 문서를 읽을 때에는 [[문자열 마법사](https://help.hancom.com/hoffice/webhelp/9.0/ko_kr/hcell/menu/data/text_separation.htm)] 대화 상자에서 문자 코드, 읽는 방식, 글꼴 등을 지정해야 합니다.
  * **인터넷 문서(*.html; *.htm)**


인터넷 문서의 기본 형식으로 쓰이는 HTML 형식의 문서를 읽어 들입니다. HTML이란 Hyper Text Markup Language의 약자로 웹 브라우저에 하이퍼텍스트 기능을 가진 문서를 만드는 언어입니다.
![](https://help.hancom.com/hoffice/webhelp/9.0/ko_kr/hcell/images/icon_refer.gif) 표나 워드숍, 차트, 수식 등의 개체가 삽입된 문서를 인터넷 문서로 저장한 다음 불러오면 올바르게 나타나지 않을 수 있습니다.
  * **dBASE 문서(*.dbf)**


데이터베이스용 파일인 DBF 파일을 읽어 들입니다.
  * **한컴오피스 문서(*.hwp; *.hwt; *.hml; *.show; *.hpt; *.hsdt; *.htheme; *.cell; *.nxl; *.hcdt; *.nxt)**


한컴오피스 문서 중에서 선택한 확장자에 해당하는 프로그램을 실행하여 문서를 읽어 들입니다. 선택한 확장자 종류에 따라 한/글(*.hwp;*.hwt;*.hml), 한/쇼(*.show;*.hpt;*.hsdt;*.htheme), 한/셀(*.cell;*.nxl;*.hcdt;*.nxt)이 실행됩니다.
##  ![](https://help.hancom.com/hoffice/webhelp/9.0/ko_kr/hcell/images/dot.gif) 주의
### ODF 지원 및 .NET Framework
한컴오피스에서는 다양한 운영 체제에서 프로그램 종류나 버전에 상관없이 모든 데이터와 문서가 상호 호환될 수 있도록 ISO 표준인 오픈 도큐먼트 포맷(ODF)을 지원합니다.
단 Microsoft .NET Framework 3.5 버전 이상이 시스템에 설치되어 있지 않으면 ODF 불러오기/저장하기 기능을 사용할 수 없으므로 .NET Framework 프로그램이 설치되어 있지 않은 시스템에서 한컴오피스를 설치하면 해당 프로그램을 기본 설치해 줍니다.
