# Open Different File Types
 |  
| --- | --- |  
|   |  File &gt; Open  |  
In Hshow, you can open and edit various file types over Hshow documents (*.show) or Slide documents (*.hpt).
##  ![](https://help.hancom.com/hoffice/webhelp/9.0/en_us/hshow/images/dot.gif) Steps
  1. Click [**File** > **Open**](https://help.hancom.com/hoffice/webhelp/9.0/en_us/hshow/file/open/open.htm).
  2. In the **Open** dialog box, click the **File Type** list button and select **Slide Documents (2004-2007) (*.hpt)**.
  3. In **Find in** , select a folder that has the document file of choice. Only the Slide documents (*.hpt) in that folder will be displayed in the file list box.
  4. Select a file of choice from the list box and click **Open**.
  5. The selected file opens in the document window.


##  ![](https://help.hancom.com/hoffice/webhelp/9.0/en_us/hshow/images/dot.gif) Note
### Supported File Formats
To open different file type from the **Open** dialog box, select the file type you want in **File Type**. Or you can also type a file type in **File Name** like *.hpt to show the list of hpt files.
  * **All Presentation Documents (*.show;*.hsdt;*.htheme;*.hpt;*.pptx;*.ppt;*.potx;*.pps;*.ppsx;*.thmx;*.odp)**
  * Read documents of various presentation programs including Hshow.
  * **Hancom Office Documets (*.hwp;*.hwt;*.hml;*.hwpx;*.cell;*.hcdt;*.show;*.hpt;*.hsdt;*.htheme;*.nxl;*.nxt)**
  * Read documents from Hancom Office program with the selected extension. Depending on the selected extension, Hwp (*.hwp;*.hwt;*.hml), Hshow (*.show;*.hpt;*.hsdt;*.htheme), or Hcell (*.cell;*.nxl;*.hcdt;*.nxt) runs.
  * **Hshow Documents (*.show)**
  * Read documents of Hshow file type.
  * **Hshow Templates (*.hsdt)**
  * Read documents of Hshow template file type. You can also read a template file by clicking **Add Design Template** button from the **Design** task pane.
  * **Hancom Office Themes (*.htheme)**
  * Read documents of Hancom Office theme file type. You can also read a theme file by running **Design > Themes > Browse Themes**.
  * **Slide Documents (2004-2007)(*.hpt)**
  * Read previous version documents of Slide 2004-2007 file type.
  * **PowerPoint Documents (*.pptx)**
  * Read documents of Microsoft PowerPoint file type.
  * **PowerPoint Documents (97-2003) (*.ppt)**
  * Read documents of Microsoft PowerPoint 97-2003 file type.
  * **PowerPoint Templates (*.potx)**
  * Read documents of Microsoft PowerPoint template file type.
  * **PowerPoint Shows (97-2003)(*.pps)**
  * Read documents of Microsoft PowerPoint 97-2003 show file type.
  * **PowerPoint Shows (*.ppsx)**
  * Read documents of Microsoft PowerPoint show file type.
  * **PowerPoint Office Themes (*.thmx)**
  * Read documents of Microsoft PowerPoint office theme file type.
  * **ODF Presentation Documents (*.odp)**
  * Read ISO Standard Open Document Format (ODF) Presentation document.


##  ![](https://help.hancom.com/hoffice/webhelp/9.0/en_us/hshow/images/dot.gif) Caution
### ODF Support & .NET Framework
Hancom Office supports an ISO standard, and ODF (Open Document Format). All data and documents are compatible regardless of program type or version.
Microsoft .NET Framework 3.5 is required to install or use Hancom Office suite.
